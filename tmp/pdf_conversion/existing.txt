A B S T R A C T
Class imbalance occurs when data is uneven between classes in machine learning classiﬁcation.
Resampling techniques can cause problems which can either add noise in the data and there is
a chance of information loss. This paper presents an investigation into Coverage-Aware Safe-
Border SMOTE (CASB). CASB is a static mixture approach combining all minority points and
borderline sparse region source points. Four variants were investigated; conditionally capped
interpolation, uncapped interpolation, followed by majority only edited nearest neighbours,
and duplication of sources. Implementation was performed using 44 two-class datasets from
KEEL. These were split using the given 5 fold splits, 2 seed values and ratio selection only
during training. The CASB implementations were compared against SVM, KNN, random forest
and logistic regression. Forty tasks were used allowing full comparisons against SMOTE,
Borderline-SMOTE, random oversampling and ADASYN. ADASYN failed on 52 occasions
across the 4 classiﬁers. Looking at random forest the retrospective family outperformed the
others on G-mean on 28 of the 40 tasks and F1 on 26. However this resulted in diﬀerent
models being selected for each metric. The static variant improvements were still signiﬁcant
after Holm correction for each classiﬁer. However the precision suﬀered. None of the paired
Wilcoxon results survived the sensitivity analysis of the source family. A separate Gaussian
overlap experiment was performed and generation diagrams were audited to understand the
underlying mechanisms. This provided evidence that the resampling strategy can be reliably
applied but will be classiﬁer dependent. Matched cleaner ablations and independent dataset
families are needed to make stronger claims of superiority.
1. Introduction
Machine learning is a branch of artiﬁcial intelligence which allows computers to learn from data. Generally
machine learning falls into three categories: supervised learning, unsupervised learning, and semi- supervised learning
. Supervised learning looks at how one or more input variables within the dataset aﬀect the outputs. Class imbalance
will cause sparse regions for the minority class, single observations and common class support. If the dataset contains
95 percent of class A samples and 5 percent of class B samples then a classiﬁer may achieve high accuracy, but will
miss out on most of the minority class samples. The accuracy will be 95% if you classify everything as the majority
class, however you have 0 minority recall. This is the main issue we had when dealing with our class imbalanced
datatset. Accuracy is misleading or not relevant in this type of task.
Oversampling techniques helps us to solve this type of problems. ROS is a random oversampling technique which
duplicates the minority class observations. SMOTE creates new synthetic points between the minority source and one
of its minority neighbours (Chawla, Bowyer, Hall and Kegelmeyer, 2002). Both approaches can aﬀect the decision
boundary which can make the classiﬁer more accurate. However just because there are more minority samples doesn’t
mean they are independent. The new points will take the label of their source. This can be problematic if the distribution
is overlapping or disjoint as the assumption that the interpolated line will have the same label can be false. Duplication
avoids geometric assumptions, however we give too much importance to the existing data points.
This study examines how a ﬁxed number of new minority class sample can be distributed among diﬀerent type of
minority observation. CASB draws the source points from three overlapping pools: all minority observations which we
called it coverage, observations in locally mixed neighbour with minority support which is boundary region, and sparse

2. Literature review
2.1. Random repetition, interpolation and diﬃcult regions
Random Oversampling will increase the weight of observations in the sample by duplicating those in the minority
class. As no assumptions have to be made about the distribution of the minority class, this provides useful information
for any interpolation based methods. However due to the lack of new features, there can be issues of duplication.
For example if there are multiple duplication of a incorrect label, this can cause issues for the classiﬁer to ﬁnd the
correct decision boundary. However, as this is an old technique it should not be overlooked as it can outperform newer
techniques in some cases and should therefore be considered a serious competitor.
SMOTE synthesises new data points for the minority class by interpolating between minority neighbours (Chawla
et al., 2002). This is attractive as the generator is simple. In basic SMOTE however, no consideration is given to the
majority points around each segment. Therefore, a short minority-minority edge may not actually be a valid minority
edge. This is because the two endpoints may be on either side of a majority region.
Borderline-SMOTE focuses on generating new data points around minority points identiﬁed as being in danger
using local labels (Han, Wang and Mao, 2005). This directly tackles the problem of uniform allocation of examples
far away from the diﬃcult boundary. Borderline-1 was used in this case. This is because the selection criteria has been
applied, and does not imply that allocating widely is always better. CASB does allocate some points to the all minority
pool to investigate this trade oﬀ.

ADASYN focuses on creating more data points for minority points that are more diﬃcult to learn locally (He, Bai,
Garcia and Li, 2008). This adapts to the data unlike the ﬁxed branch allocation in CASB. A high majority proportion

The issues with ADASYN in this project was down to practical reasons. Any tasks that could not be completed by one
method were not included in any of the methods for the matched cohort.
2.2. Safety, density and minority instance types
The Safe-Level-SMOTE modiﬁes the interpolation method with the local minority support (Bunkhumpornpat,
Sinapiromsaran and Lursinsap, 2009). The Geometric SMOTE samples from a conﬁgurable geometric area instead of
just from the original SMOTE line segment (Douzas and Bacao, 2019).The CASB wants to make sure local details
are included in the sampling process. This algorithm has reduced ﬂexibility by limiting the displacement based on the
branch for each sample. The displacement is limited in relation to the closest majority observation. However, there is no
restriction on the coverage of the algorithm. Limiting the distance between the samples and source observations does
not guarantee that the generated sample will have the correct label, particularly if the source is incorrectly labelled.
Density based methods are key. DBSMOTE takes advantage of the density structure when creating new points
(Bunkhumpornpat, Sinapiromsaran and Lursinsap, 2012). K-means/SMOTE distribution takes advantage of the
clusters by distributing the new points evenly between them (Last, Douzas and Bacao, 2017). This leads to looking at
other measures than the overall class distribution. The CASB takes advantage of a basic measure of local sparsity by
measuring how far away samples are from their third closest minority class neighbour. It then ﬁnds the highly sparse
samples by taking the 75th percentile value. This does not explicitly ﬁt clusters to the data however, it should not be
taken as ﬁnding real minority sub populations. The distances will also depend on the features used and may become
less useful in high dimensional spaces
I ﬁnd that categorizing minority instances is a task that feels very similar to related tasks. According to Napierala
and Stefanowski (2016) the authors distinguish between borderline, rare and outlier examples by using the local
class structure. The authors in Skryjomski and Krawczyk (2017) study class- oversampling with SMOTE. Local
Neighborhood Encodings (LNE) adaptively optimize resampling rates for neighborhood-classiﬁed classes and Local
Neighborhood Encodings (LNE) use both oversampling and undersampling techniques (Koziarski and Woźniak, 2024).
Knowing which class to generate instances from has thus already been studied. The importance of the minority
instances in datatset remains clear. CASB uses -evolutionary ﬁxed weights to combine multiple pools. CASB remains
an approach. This benchmark does not consider using LNE therefore no demonstration of an advantage for CASB,
over such a technique is possible.
2.3. Cleaning and uncertainty-guided frameworks
The edited nearest neighbour approach cleans the data by removing the any discordant sample points. Here we
use the implementation from the imbalanced-learn library which provides a clear insight into what samples are being
cleaned and what voting strategy has been used (cite). When using a cleaning strategy, there is much more adjustment
to the training set. This can be due to the synthetic samples aﬀecting the vote during the cleaning process. As this uses
a well known cleaning strategy it is not considered as an ENN approach.
While the classic comparison between SMOTE and ENN is useful, it cannot act as a paired control strategy. CASB-
edited uses a focus on the majority class samples using a k-NN strategy where k=3. Often hybrid approaches will have
parameters to give focus to a particular class or selection. Therefore there is no indication that there is any beneﬁt to
the CASB generation. An improved control strategy for the future would be to use SMOTE and only clean the majority
class using the same cleaning strategy.
UGO uses uncertainty to select what samples will be generated from. This requires multiple reﬁtting of the classiﬁer
and ﬁltering of the samples. Once generated, samples are moved (cite). Generators are switched within the framework.
CASB uses the idea of separating the generation and allocation process experimentally. However the allocation process
uses a ﬁx neighbour calculation. As they have similar structures it is diﬃcult to predict how computational and statistical
the systems will be. UGO results have not been included in the CASB tables.

Original CASB. Original, with 50/30/20 ratios. This aims to be relatively conservative by ensuring that some
allocations are made to local mixed and sparse regions. The term safe in CASB refers to the aim.
CASB-relaxed Relaxed, 70/20/10 ratios. For each non-zero edge 𝜆max = 1. The pooling, fallback and rare neighbour
restrictions are identical to the original. The all-minority ratio is increased and there are no limits. Therefore the
diﬀerence between the original and relaxed versions is due to both factors.

CASB-edited Edited method starts by generating using the relaxed version. The ENN method is applied, but we only

can be higher than required. An error is raised if less than 2 majority observations are present in the implementation.

guided repetition works, but due to the diﬀerences in ratios chosen and rounding, it is not a full ablation study of the

3.5. Computation and auditability
Nearest-neighbour structures are ﬁtted to full data, minority data and majority data. Under brute-force searches,
computing the required neighbourhoods costs up to 𝑂(𝑛𝑚𝑛𝑝) distance arithmetic, with neighbour selection overhead
depending on the backend. Generation costs 𝑂(𝐺𝑝) once neighbour lists are stored. ENN adds a neighbourhood search
on the augmented data, with a brute-force upper bound of 𝑂((𝑛+ 𝐺)2𝑝). Tree-based searches can improve particular
low-dimensional cases, but no universal logarithmic claim is made. Stored features and output require 𝑂((𝑛+ 𝐺)𝑝)
memory; explicit audit records require 𝑂(𝐺) additional entries. Library search batching aﬀects temporary memory.
Per-addition audits record source, neighbour, overlap, support, majority distance, branch and interpolation bounds,
permitting direct checks of 𝑧= 𝑥𝑠+ 𝜆(𝑥𝑡−𝑥𝑠). No controlled runtime benchmark is claimed.

4.2. Simulation design
The controlled overlap experiment has two features and identity covariance for both classes. Majority observations
follow 𝑁((0, 0), 𝐼) and minority observations follow 𝑁((𝑑, 0), 𝐼), with 𝑑∈{0, .5, … , 5}. Each seed generates 400
majority and 40 minority training points and an independent test set of 1,000 majority and 100 minority points.
Twenty seeds, 20260–20279, are used. Base random draws are reused across distances and methods within a seed,
which improves pairing but correlates distance-speciﬁc outcomes.
This experiment varies geometric overlap, not corrupted-label percentage. The separate generation illustrations
contain deliberately injected labels where indicated, but are not a quantitative label-noise robustness study. There are
20×11×9×4 = 7,920 simulation attempts, 7,912 successes and eight ADASYN failures. Each classiﬁer has two failures
at distance 5. Curve cells require all twenty successful repeats; incomplete cells are omitted. Simulation averages use
the ten complete distances for every method.
4.3. Compared methods and classiﬁers
The core comparison includes no resampling, SMOTE, Borderline-SMOTE, ROS, ADASYN and the four CASB
variants. The number of minority neighbours for library interpolation methods is min(5, 𝑛𝑚−1); B-SMOTE uses
borderline-1. The extended SVM/KNN statistical comparison adds compatible RUS and SMOTE-ENN results. Those
controls are unavailable under the RF/LR expanded protocol, and no values are inferred for them. Library components
follow the project implementation (Lemaître, Nogueira and Aridas, 2017; Pedregosa, Varoquaux, Gramfort, Michel,
Thirion, Grisel, Blondel, Prettenhofer, Weiss, Dubourg, Vanderplas, Passos, Cournapeau, Brucher, Perrot and Duch-
esnay, 2011).
SVM uses an RBF kernel, 𝐶= 1 and gamma=scale. KNN uses distance weighting and seven neighbours, reduced
only when fewer than seven training observations remain. RF uses 100 trees and minimum leaf size two. LR uses its
implemented default regularization with a maximum of 3,000 iterations. None of these four uses class weights in the
reported current comparison. Classiﬁer hyperparameters and prediction thresholds are not searched.
RF and LR were retained for presentation after their results were inspected. Gaussian naive Bayes was also evaluated
and is reported as an auxiliary result rather than hidden. This post-hoc classiﬁer selection makes the four-classiﬁer
presentation exploratory. A future conﬁrmatory experiment must freeze classiﬁer inclusion before outcomes are known.
4.4. Application protocol and metrics
Every outer training fold is split into an inner training partition and a stratiﬁed 25% validation partition. Each
sampler tries ratios .50, .75 and 1.00. Selection maximizes (𝐺-mean + 𝐹1)∕2 on the validation partition, with ties
preferring the smaller ratio. This quantity selects a ratio; it is not the paper’s composite success criterion. Imputation
and scaling are ﬁtted anew in every inner ﬁt. The chosen pipeline is reﬁtted on the full outer training fold, then applied
to untouched outer test features.
The two Abalone tasks contain a categorical Sex attribute. Training-ﬁtted most-frequent imputation and dense
one-hot encoding handle that attribute, with unknown test categories ignored. Numeric features follow the ordinary
numeric pipeline. Interpolation can create fractional dummy values, so this is an encoded-space experiment, not a
categorical-aware generator. Comparison with SMOTENC remains future work.

4.5. Aggregation, family summaries and statistical procedure
For dataset 𝑑, classiﬁer 𝑐, method 𝑎and metric 𝑚, let 𝑆𝑑𝑐𝑎𝑚be the mean of its ten outer evaluations. An incomplete
group is withheld. Collection-wide averages are 𝐴𝑐𝑎𝑚= |𝐷|−1 ∑
𝑑𝑆𝑑𝑐𝑎𝑚. Combined tables average classiﬁers equally
after averaging datasets; a large dataset does not receive more weight.
Two diﬀerent retrospective quantities are reported. The collection envelope is max𝑎∈𝐴𝑐𝑎𝑚, choosing one ﬁxed
family member for an entire metric column. Dataset-wise family wins count max𝑎∈𝑆𝑑𝑐𝑎𝑚> max𝑏∈𝑆𝑑𝑐𝑏𝑚. The
second may select a diﬀerent variant on each dataset. Neither is a deployable selector or a basis for a conﬁrmatory
paired test. A joint G-mean/F1 win requires a single variant to exceed every baseline on both metrics. Ties use tolerance
10−12.
Fixed-variant inference uses two-sided Wilcoxon signed-rank tests on paired dataset means, following the multiple-
dataset comparison framework of Demšar (2006). Pairs without ADASYN use 44 datasets; ADASYN pairs use 40.
Zero diﬀerences are omitted; diﬀerences are rounded to twelve decimals for ranking and the tie-corrected asymptotic
calculation is used. Symmetry of the paired-diﬀerence distribution and dependence among tasks limit interpretation.
Holm correction (Holm, 1979) spans four variants, all compatible baselines and four metrics separately within each
classiﬁer: 112 tests for SVM/KNN and 80 for RF/LR.
Friedman tests use the strict 40-task cohort, with eleven methods for SVM/KNN and nine for RF/LR. Four omnibus
tests per classiﬁer are Holm-corrected; post-hoc all-pairs results have their own correction family. Source-family mean
diﬀerences and one lexicographically selected task per source family provide separate sensitivity populations. Exact
sign tests are also retained, rather than choosing whichever test produces a desired conclusion. Classiﬁer retention and
development reuse are not erased by these corrections.

5.2.4. Training-only selection and auxiliary classiﬁer evidence
The historical selector chooses among original, relaxed and edited CASB and three ratios using saved inner-
validation scores. CASB-ROS was not a candidate. Reusing the corresponding saved outer reﬁt is valid for that recorded
selection decision, because no outer score enters the decision. It remains a retrospectively speciﬁed procedure on
development data. Table 13 reproduces its SVM/KNN metrics over all 44 tasks. The equal-classiﬁer G-mean is 83.066%
and F1 is 68.001%; these values cannot be compared directly with a forty-task envelope. The selector has nine inner
trials versus three for a ﬁxed baseline, so it also has a diﬀerent search budget. No RF/LR selector performance is
inferred.
Gaussian naive Bayes provides an additional negative check on selective presentation. On the forty-task cohort,
edited G-mean is 68.310% versus SMOTE’s 67.699%, and edited F1 is 46.971% versus 46.142%. Edited recall is
85.216%, below ADASYN’s 86.790%. These results remain part of the evidence even though GNB is not a main
ﬁgure panel. Future comparisons should declare the complete classiﬁer set in advance.

5.3. Mechanistic Interpretation of Metric-Speciﬁc Performance Tradeoﬀs
5.3.1. Conﬁrmed implementation mechanisms
Original CASB limits displacement in capped branches. Relaxed changes both quotas and displacement; edited
adds majority-only removal. CASB-ROS changes multiplicities without creating new coordinates. These statements
follow from the code and do not depend on whether a metric improves. Original CASB is not a noise ﬁlter, and edited
does not clean minority labels.
More minority predictions may reduce 𝐹𝑁while increasing 𝐹𝑃. G-mean improves only when the recall–
speciﬁcity product increases; majority deletion provides no monotonic improvement guarantee.
5.3.2. Veriﬁed observations from confusion matrices
Table 14 uses recorded confusion matrices to compare edited with original CASB. False-positive and false-negative
rates are computed within each fold, then averaged within dataset and across the forty matched tasks. This avoids
allowing large test sets to dominate a pooled confusion matrix. The table also quantiﬁes majority removals from saved
diagnostics, using the original majority training count as denominator.
These observations support an average tradeoﬀbetween majority error and minority detection, but do not isolate
quotas, interpolation, ratio selection or cleaning. Independently selected ratios also prevent edited-versus-relaxed from
being a ﬁxed-ratio cleaning ablation.

5.3.3. Plausible explanations and their limits
The restricted generator can produce a more locally concentrated minority representation, which may preserve
precision by limiting inﬂuence far from a source. This is a plausible explanation for original CASB’s relative
precision/F1 strength, not a causal ﬁnding. The recorded outcomes do not show that original CASB always has fewer
false positives than SMOTE. A cap-only ablation with equal quotas and ratio is necessary to test that claim.
KNN responds directly to the labels and distances of nearby training points. Exact copies can aﬀect neighbourhood
composition, while interpolated points can change which observations are nearest. The RBF SVM responds to the
regularized margin and kernel similarities; duplicate weighting and new coordinates need not have the same inﬂuence.
RF changes its splits and leaf class proportions as resampling changes empirical counts. LR responds through its ﬁtted
linear score and empirical loss. These familiar classiﬁer properties explain why diﬀerent eﬀects are plausible, but the
benchmark does not identify a universal causal rule linking each source type to each classiﬁer.
CASB-ROS gains over ROS are consistent with useful guided weighting, but do not establish that interpolation is
unnecessary. Table 10 retains its losses. Edited recall gains cannot demonstrate minority-noise removal because the
implementation preserves every minority point.

5.5. Discussion, ablation needs and threats to validity
The available variants are informative conﬁgurations, not a complete factorial ablation. Original versus relaxed
changes two factors. Edited versus relaxed can change the selected ratio as well as invoke cleaning. CASB versus
CASB-ROS changes coordinates and potentially validation-selected ratios. A controlled study should hold ratios and
random source draws ﬁxed while independently varying coverage-only allocation, border allocation, rare allocation,
caps and cleaning. The largest immediate gap is SMOTE followed by the exact majority-only three-neighbour mode
cleaner.

Neighbourhood size, overlap thresholds, the sparsity quantile and margins were not exhaustively assessed. Their
interpretation can change with dimensionality, scaling, duplicate observations and minority sample size. The third-
neighbour statistic may treat a legitimate sparse component and a mislabeled observation similarly. Positive distance
and support checks restrict some branches but do not protect the all-minority pool. A future label-noise experiment must
corrupt training labels under declared rates and evaluate on clean independent tests; the current overlap experiment
does not answer that question.
The benchmark uses supplied folds and two seeds, with development reuse and related tasks. Exact repeated feature
vectors can occur across supplied partitions; a group-disjoint sensitivity analysis remains needed. Repeated seeds
measure stochastic variation, not new populations. The statistical failure under source-family grouping is reported as
a limitation of the present evidence and motivates independent data collection. It should not be reframed as a promise
that a future test will become signiﬁcant.
Baseline coverage is another constraint. Core comparisons answer whether CASB conﬁgurations help relative to
familiar resamplers. They do not establish superiority over Safe-Level-SMOTE, Geometric SMOTE, LNE, density-
aware methods or UGO, none of which is benchmarked here. Compatible historical RUS/SMOTE-ENN data improve

6. Conclusion and future work
CASB combines broad minority eligibility with ﬁxed allocation to supported borderline and sparse sources. Its
four variants use conditional interpolation, relaxed interpolation, majority-edited interpolation and guided replication.
Audited rules make the framework reproducible; its displacement bound is not a label or generalization guarantee.
The forty-task matched benchmark shows classiﬁer-dependent beneﬁts. RF has retrospective family wins on G-
mean in 28 tasks and F1 in 26 against the four core resamplers, but only twenty same-variant joint wins. RF’s best
family mean F1 remains slightly below SMOTE. Some ﬁxed-variant gains survive correction, while precision losses
and the absence of corrected source-family Wilcoxon ﬁndings prevent a broad superiority claim. The simulation and
projected examples help explain the implemented behaviour without demonstrating label-noise robustness.
Future work requires matched component controls, direct comparisons with close predecessors, categorical-aware
generation and frozen selection on new source families. The contribution is a reproducible incremental design with
measured tradeoﬀs, not universal superiority.
Data, code and research transparency
The editable project includes ﬁgures, generated tables, complete statistical CSVs and input hashes. The workspace
retains all 44 executed notebooks and the shared implementation. Current results supersede the older two-classiﬁer
guide. Public archive location, author contributions, funding and competing-interest declarations require author
conﬁrmation.
